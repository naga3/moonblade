# 月影の剣の音（PX-13h Music の moonblade グループ）

ゲームは320×240の横スクロール剣アクション。従来のコード生成音を、編集できる `.song` に移した。

- `field.song`: 森・水路・城・ボス戦のBGM。イ短調、テンポ120、4小節。元のメロディと低音の並びを保ち、ファミコンの矩形波メロディと三角波ベースにした。ゲームでは1周を繰り返す。最後から頭につながるようにする。
- `title.song`: タイトル画面の曲（仮）。イ短調、テンポ92、8小節を繰り返す。タイトルで何かキーを押すかタップすると鳴り始める（ブラウザの制限）。
- `jump`（ジャンプ）、`sword`（剣）、`hit`（命中）、`hurt`（被ダメージ）、`gem`（宝石）、`bounce`（下突きの跳ね返り）、`check`（旗・エリア開始）、`win`（ボス撃破・クリア）は効果音。各 `.song` は短い音、1回だけ鳴る。曲と同様にMusicで編集・試聴できる。
- 音源は `mode famicom`（矩形波2、三角波、ノイズ、DPCM）。音色・エンベロープをファイルに書き、別の曲に依存させない。効果音では音の高さのエンベロープで上昇・下降を付けている。
- 効果音のテイスト（2026-10-27、`bounce` で 3 方向から選んだ「重く踏んで跳ね返す」）: 全部の効果音をこれにそろえる。
  - 頭に低い打撃で踏み込む: 三角波をすばやく下げる「ドゥン」（p: 0 -24 -48 ...）、ノイズの低め（o4 g、短く減衰）、DPCM のキック（c）など。効果音の重さに応じて組み合わせる
  - 本体は 50%（@2）の太い矩形波。高さのエンベロープで上昇・下降を付ける（少し下から入って、だんだんゆっくりになる形）
  - 2 つ目の矩形波に、同じ音色を 32 分遅らせて小さく（v6 前後）重ね、厚みを出す
  - 細い 12.5% の鋭い音、25% で和音を段々に上がるきらめきは選ばれなかった。使うなら宝石など一部だけ、本体ではなく添えに
  - 長さは 8 分音符（約 0.25 秒）前後。勝利・クリアなど特別なものだけ長くしてよい
- ファイル名はゲームの音イベントに対応するので変えない。候補の選択は隣の `.picks.json` から反映される。

Musicで保存すると `node tools/audio.mjs` が、Musicと同じ `engine.wasm` でWAVを生成し、`dist/audio-data.js` に埋め込む。BGMは2周目から1周を切り出して継ぎ目を整える。ゲーム実行時はPX-13hや通信は不要。`npm start` のローカル画面は書き出し後に自動で読み直す。公開URLへは `main` に push すると反映される。
