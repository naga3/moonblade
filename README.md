# 月影の剣 / MOONBLADE

月夜の森、古い水路、城門を進む横スクロール剣アクション。全3エリア、最後に剣士との戦闘があります。

`dist/index.html` をブラウザで開くか、`npm start` で http://localhost:4173 を開いてください。ゲーム本体に外部ライブラリや通信は不要です。

| 操作 | キー |
| --- | --- |
| 移動 | ← → / A D |
| 剣 | Z / J |
| ジャンプ | X / K / Space（長押しで高く） |
| 上突き | ↑ / W + 剣 |
| 下突き | 空中で ↓ / S + 剣 |
| 開始・決定 | Enter |
| 一時停止 | P / Esc |
| 操作説明 | H |
| 音の切り替え | M |

下突きで敵に当たると跳ね返ります。旗で体力が2回復し、落下時の復帰地点になります。体力がなくなったらそのエリアから再挑戦。スマートフォンではゲーム画面内にタッチボタンが出ます。右端の門を目指してください。

描画解像度は **320×240**。共通の固定 **64色パレット1枚**を使い、すべてのピクセルを色番号で描画します。プレイヤー、敵、地形タイルは **16×16**。剣とエフェクトは別描画。文字も自作ビットマップで描き、HUD・説明・タッチボタンまで320×240内に収めています。表示領域に応じて整数倍に拡大し、320×240未満の端末では縮小します。

グラフィック、フォント、効果音、簡単な音楽はすべてコードで生成しています。画像・音声ファイルやフォントのダウンロードはありません。

ブラウザ検証: `npm install`、`npx playwright install chromium`、`npm test`。通常操作、ジャンプの高さ、剣の3方向、下突きの跳ね返り、チェックポイント、ポーズ、3エリアとボスの攻略、実フレームバッファの色数、モバイル表示を確認します。テスト専用フックは `?test` のときだけ有効です。
